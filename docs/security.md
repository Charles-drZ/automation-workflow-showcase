# Security

- Credentials are stored in the n8n credential store rather than hardcoded in workflow content.
- No tokens or authorization headers are committed to this repository.
- Live webhook details, endpoints, and private responses are excluded.
- Examples are synthetic and contain no real people, repositories, commit identifiers, or issue identifiers.
- Source access should use the least privilege needed, with read-only access where possible.
- A human approval step is required before writing durable project memory.

These practices make the public explanation useful without publishing the operational configuration.
